# 前言

## 这本书解决什么问题

Rust 官方文档《The Rust Programming Language》（俗称 The Book）质量很高，但它是英文的，面向已有一些编程经验的读者。很多中文读者卡在三个地方：

1. **所有权**：第一次遇到借用检查器的报错，不知道它在保护什么。
2. **抽象工具**：泛型、trait、生命周期三件套同时出现时，读不懂函数签名。
3. **从会语法到能干活**：能看懂示例，但写不出一个带错误处理、测试和日志的真实项目。

这本书按"先建立心智模型，再补语法细节，最后落到工程项目"的顺序组织，尽量用中文把每个设计决策背后的原因讲清楚。每一章都不止讲语法，还会给出编译器与运行时的实际行为、性能代价、边界情况，以及几个真实会踩的报错案例。它不替代官方文档，而是给你一条能走通的路：读完一章，你能动手写出对应的代码，并且知道编译器为什么接受或拒绝它。

本书开源于 [yujh129/rust-book-zh](https://github.com/yujh129/rust-book-zh)，在线阅读版是 [yujh129.github.io/rust-book-zh](https://yujh129.github.io/rust-book-zh/)。发现错字、跑不通的代码，或者想补充内容，欢迎到仓库的 [Issues](https://github.com/yujh129/rust-book-zh/issues) 提出。

## 本书的结构

| 部分 | 内容 | 读完之后 |
| --- | --- | --- |
| 第一部分 起步 | 工具链、变量与类型、函数与控制流、复合类型、所有权、引用、切片 | 能写几百行的小程序，看得懂借用报错 |
| 第二部分 抽象与数据建模 | 结构体、枚举、错误处理、模块、集合、迭代器、泛型、trait、生命周期 | 能设计库的公开 API，读懂标准库签名 |
| 第三部分 内存与资源 | 智能指针、内部可变性、内存布局 | 知道数据放在哪、什么时候释放、为什么这样设计 |
| 第四部分 并发与异步 | 线程、共享状态、通道、Future、Tokio | 能写多线程与异步程序，理解 Send/Sync |
| 第五部分 工程实践 | 测试、错误处理策略、日志、serde、clap、axum、CI 与发布 | 能独立交付一个可维护的 Rust 项目 |
| 第六部分 深入语言 | 声明宏、过程宏、unsafe、类型系统进阶、设计模式、错误速查 | 能读懂框架源码，知道什么时候该用 unsafe |
| 第七部分 项目实战 | mini-grep、JSON 解析器、多线程 HTTP 服务器、mini-redis、异步聊天室、终端贪吃蛇 | 从零写出六个完整可运行的项目，能放进简历和 GitHub |

前三部分请按顺序读：第 5～7 章的所有权是全书地基，第 14～17 章的类型系统是后半本书的语法基础。第四、五、六部分可以按兴趣跳读。第七部分的每个项目都自成一个完整程序，建议在学完对应主题后回来动手实现，不要只读代码。

六个项目的完整源码都在仓库的 `projects/` 目录里（只有聊天室直接依赖 Tokio，其余五个只用标准库），每章末尾的「完整源码」小节列出了每个文件负责什么、怎么跑。卡住时可以对照真实实现，也可以在它的基础上继续改。

## 书里的代码怎么用

**在网页里直接改和跑。** 完整的单文件示例可在网页运行，多文件片段、终端记录和配置需按所在小节在本地使用：

- **复制**：把代码拷到剪贴板。
- **编辑 / 运行**：点按钮后可以在页面内直接改代码，再点运行，输出就显示在代码下方。

标为可编辑的错误案例可以直接动手：先点一次运行，看编译器怎么报错；再照着下面的「修复」把错的那一行改掉，点第二次运行，对比两次结果。这一改一跑，比读十遍解释都管用。

每段案例的**原因**与**修复**默认是收起的，先自己判断错在哪，再点「查看答案」展开对照。每条答案的最后都给出修复后的完整代码，可以直接跑一遍确认。打印或导出 PDF 时答案会自动展开。

默认情况下代码发给官方 Rust Playground（`play.rust-lang.org`）执行，需要联网。网络不通、或者只是想更快一点，可以用仓库自带的本地运行器让代码在你自己的机器上离线编译运行，做法见 [1.8 在浏览器里改代码、跑代码](00-setup.md)。两边看到的结果形态一致：报错都是 `rustc` 的真实输出。

**在本地编辑器里。** 自包含的二进制示例可以拷进 `src/main.rs`。库、集成测试、宏和多文件示例请按章节给出的路径放置，并安装清单中的依赖。第七部分的项目不必从零搭：`projects/` 下已经有六个能直接 `cargo run` / `cargo test` 的工程，`cd` 进去就能跑，想重写一遍再自己 `cargo new` 一个对照。

## 阅读约定

- 代码块左上角标注语言。`console` 表示终端输入输出，`$ ` 开头的是你输入的命令。
- **加粗**的是关键结论；`> **本章目标**` 引用块列出这一章要建立的能力。
- 每章都有"典型错误案例"：给出错误代码、预期现象、原因和修复；有些问题直到运行或测试时才暴露。建议在遇到报错时回来对照。
- 每章结尾有"动手练习"，至少完成前两题。

## 版本说明

本书使用 **Rust 2021 edition**，本轮核验使用 `rustc 1.100.0`。新建配套项目可执行 `cargo new --edition 2021 项目名`。edition 决定一组语言规则，能用哪些标准库 API 则取决于工具链版本，例如第 19 章的 `LazyLock` 从 1.80 起稳定。

复现实验时优先使用配套工程的 `Cargo.lock`，自建项目则使用章节给出的依赖系列和 feature。跨不兼容版本升级时，请核对对应版本的 API 文档。

## 怎么读才有效

1. **每段代码都自己敲一遍**，不要复制粘贴。手的记忆比眼睛可靠。
2. **主动制造错误**。把示例里的 `&` 去掉、把 `mut` 删掉、把 `clone()` 换成移动，看编译器怎么说。读懂报错是 Rust 的核心技能。
3. **不要背规则，记模型**。借用检查器不是一堆禁令，而是"同一时刻，一个值要么有多个只读引用，要么只有一个可写引用"这一条模型加上若干推论。
4. **卡住超过 30 分钟就看答案**。先看本章小结，再回看对应小节，最后才去搜。多数问题在第 5～7 章和第 17 章已经有解释。
5. **每个项目至少扩一个功能**。项目章节最后都列了扩展练习，那是把知识变成能力的地方。

## 与官方资料的关系

本书的章节顺序参考了 The Book 的主线，但做了三处调整：把切片与字符串边界单独成章（第 7 章），把 trait 拆成基础与进阶两章（第 15、16 章），并把工程实践（第五部分）提前到 unsafe 之前——大多数读者更需要先能交付项目，而不是先读懂 `MaybeUninit`。第七部分把这些主题放进六个项目；其中命令行搜索和多线程 Web 服务器也可与官方教程的相关项目对照阅读。

如果你已经能独立写 Rust，可以直接从第 18 章开始；如果只想知道某个报错怎么修，翻第 38 章。
